## Global Constraints

Các ràng buộc này áp dụng cho **mọi** task và là căn cứ review:

1. Không đổi persist key `restodash-pos-v1`; nâng version **2 → 3** và có migration/test. Không đổi `restodash-catalog-v1`.
2. Không đưa đơn mở lên server. Server chỉ nhận đơn đã thanh toán như hiện tại (`OrderStatus.COMPLETED | VOIDED`).
3. Trạng thái bàn **suy ra từ đơn mở**, không lưu cột trạng thái bàn.
4. Một thời điểm chỉ có **một đơn active** trong `cart/tableId/discount/note`; các bàn khác nằm trong `openOrders`.
5. `CartLine.served === true` là món đã mang ra: khoá sửa/xoá; thêm món trùng phải tạo dòng mới `served: false`.
6. Offline-first: thêm/xoá bàn và mọi thao tác đơn phải chạy khi mất mạng; queue bàn flush khi có mạng.
7. Bàn chưa có `serverId` UUID thật thì thanh toán gửi `tableId` rỗng, vẫn giữ `tableName` local.
8. Quyền thêm/xoá bàn: `OWNER`, `MANAGER`. Mọi role được tick served và thanh toán.
9. UI tiếng Việt; trạng thái bàn luôn có **nhãn chữ + icon**, không chỉ màu.
10. Không thêm dependency runtime; không đổi brand RestoDash → Serva trong module này.
11. Không fake số liệu, không mock trong production code, không sửa ngoài phạm vi task.
12. Mỗi task: viết test fail trước (TDD), implement, chạy test liên quan, chạy full suite một lần trước commit, commit sạch.

**Mục tiêu:** nhiều đơn mở, chuyển bàn không mất giỏ, served theo từng món, khoá món đã ra.

**Interfaces**

```ts
// src/lib/table-state.ts

export function orderKey(tableId: string | null): string
```

```ts
// usePOSStore
openOrders: Record<string, OpenOrderSnapshot>
switchTable: (tableId: string | null) => void
setLineServed: (lineId: string, served: boolean) => void
setAllServed: () => void
isTableBusy: (tableId: string) => boolean
```

**Hành vi bắt buộc**

- `addItem(menuItemId)`:
  - tìm dòng cùng `menuItemId` và `served !== true` → `qty + 1`;
  - nếu không có → tạo dòng mới `served: false`;
  - dòng mới luôn có `unitPrice`, `name` như hiện tại.
- `increment`, `decrement`, `removeItem`: no-op nếu dòng có `served === true`.
- `setLineServed(lineId, served)`: chỉ đổi dòng đó.
- `setAllServed()`: set `served: true` cho mọi dòng.
- `isTableBusy(tableId)`: true khi bàn đang active có cart không rỗng, hoặc `openOrders[tableId]` có cart không rỗng.
- `switchTable(next)`:
  1. `currentKey = orderKey(state.tableId)`, `nextKey = orderKey(next)`.
  2. Nếu bằng nhau → chỉ `{ tableId: next }`.
  3. Nếu `cart.length > 0` → lưu `openOrders[currentKey] = { cart, discount, note, updatedAt: Date.now() }`; nếu cart rỗng → xoá snapshot `currentKey`.
  4. Lấy `openOrders[nextKey]`; nếu có → nạp `cart/discount/note` và xoá khỏi map.
  5. Nếu không → `emptyOrder()`.
  6. Set `tableId: next` và `openOrders` mới.
- `setTable` giữ tên nhưng gọi `switchTable`.
- `resetOrder`: xoá active + snapshot `orderKey(tableId)`, giữ nguyên các bàn khác; vẫn set `tableId: null` như hành vi cũ.
- `saveDraft`: xoá snapshot `orderKey(tableId)` trước khi `emptyOrder()`.
- `loadDraft`:
  - nếu `draft.tableId` khác bàn active và cart hiện tại không rỗng → cất cart hiện tại vào snapshot;
  - xoá snapshot của `orderKey(draft.tableId)` để tránh trùng;
  - nạp draft, xoá draft khỏi danh sách.
- `completeOrder`: sau khi tạo order, xoá snapshot `orderKey(tableId)` và `emptyOrder()`.
- Không đổi `completeOrder` ở chỗ gửi `payload.tableId`: chỉ gửi khi `table.serverId` tồn tại.

**Interfaces**

```ts
// src/types.ts
export interface TableFormInput {
  name: string
  seats: number
  zone?: string | null
}

export interface CreateTablePayload extends TableFormInput {
  legacyId: string
  sortOrder?: number
}

export type TableOp =
  | {
      id: string
      kind: 'CREATE_TABLE'
      tableId: string
      payload: CreateTablePayload
      createdAt: number
    }
  | {
      id: string
      kind: 'DELETE_TABLE'
      tableId: string
      serverId: string
      createdAt: number
    }

export interface TableOption {
  // ...hiện có
  syncState?: 'pending' | 'synced'
}
```

```ts
// src/api/tables.ts
export function getTables(): Promise<ServerTable[]>
export function createTable(input: CreateTablePayload): Promise<ServerTable>
export function deleteTable(id: string): Promise<void>
```

```ts
// useCatalogStore
pendingTableOps: TableOp[]
createTable: (input: TableFormInput) =>
  | { ok: true; tableId: string }
  | { ok: false; reason: 'DUPLICATE_NAME' | 'INVALID' }
deleteTable: (tableId: string, blockedByOpenOrder?: boolean) =>
  { ok: boolean; reason?: 'OPEN_ORDER' | 'NOT_FOUND' }
flushTableOps: () => Promise<void>
```

**Hành vi**

- `createTable`:
  - trim name/zone; name 1..50; seats integer 1..50; zone ≤ 50.
  - trùng tên (case-insensitive) với bất kỳ bàn local nào → `DUPLICATE_NAME`.
  - `id = 'ban-' + makeId()`; `legacyId = id`.
  - thêm local `{ id, name, seats, zone: zone || null, syncState: 'pending' }`.
  - enqueue `CREATE_TABLE` với payload `{ legacyId: id, name, seats, zone: zone || null }`.
  - **không** gọi API trực tiếp; caller gọi `flushTableOps`.
- `deleteTable(tableId, blockedByOpenOrder = false)`:
  - `blockedByOpenOrder` → `{ ok: false, reason: 'OPEN_ORDER' }`.
  - không tìm thấy → `{ ok: false, reason: 'NOT_FOUND' }`.
  - xoá bàn khỏi local ngay.
  - nếu có CREATE op đang chờ → bỏ op đó, không enqueue DELETE.
  - nếu có `serverId` → enqueue `DELETE_TABLE`.
  - trả `{ ok: true }`.
- `flushTableOps`:
  - module-level in-flight promise để không chạy song song.
  - xử lý tuần tự từng op.
  - CREATE thành công → cập nhật bàn local: `serverId = response.id`, `name/seats/zone` theo response, `syncState: 'synced'`; xoá op.
  - CREATE lỗi mạng (`ApiError.isOffline`) → dừng, giữ op.
  - CREATE lỗi HTTP khác → xoá op (terminal), giữ bàn local `pending`.
  - DELETE thành công hoặc 404 → xoá op.
  - DELETE lỗi mạng → dừng.
  - DELETE lỗi HTTP khác → xoá op.
- `refresh`:
  - `await flushTableOps()` trước khi GET.
  - merge server tables với:
    - local tables `syncState === 'pending' && !serverId` (giữ bàn chưa sync);
    - ẩn server tables có `serverId` nằm trong pending DELETE.
  - `mapTables` set `syncState: 'synced'`.
- `BUILTIN_TABLES`: **bỏ `serverId` giả** (`ban-1` không phải UUID). Builtin tables giữ `id/name/seats`, không có `serverId`.
- `onRehydrateStorage`: bỏ `serverId` không phải UUID khỏi cache cũ (dùng regex UUID) để tránh gửi `tableId` sai.
- `partialize` thêm `pendingTableOps`.
- `deleteTable` không tự kiểm tra open order (tránh import cycle); UI truyền `blockedByOpenOrder`.

Mock `../api/tables` và `../api/menu` bằng `vi.mock`.
